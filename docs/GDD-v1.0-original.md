# 《拾色者 Color Bloom》
## 游戏设计与玩法说明（GDD v1.0）

---

# 1. 游戏概述

## 1.1 游戏定位

《拾色者》是一款以色彩恢复为核心的休闲射击解谜游戏。

游戏发生在一个失去色彩的世界里。灰雾笼罩着大地，所有物体都失去了原本的颜色。

玩家需要从屏幕底部发射不同颜色的光球，击中上方不断下落的灰色色块，为它们重新赋予颜色。

随着灰色色块逐渐被染色，世界也会慢慢恢复生机。

**核心理念：每一次射击，都让世界变得更美好一点。**

## 1.2 基本信息

| 项目 | 设计 |
|---|---|
| 游戏类型 | 休闲射击 + 轻度解谜 |
| 游戏平台 | iOS / Android |
| 游戏方向 | 竖屏 |
| 操作方式 | 单指拖拽、松手发射 |
| 核心元素 | 颜色球、灰色色块、彩虹爆发 |
| 单局时长 | 1–3分钟 |
| 游戏节奏 | 轻松、解压、逐渐增加挑战 |
| 主要目标 | 将灰色世界恢复成彩色世界 |

---

# 2. 核心游戏循环

整个游戏围绕一个非常简单的循环展开：

1. 灰色色块从屏幕顶部不断出现并向下移动。
2. 玩家从底部三个颜色球中选择一种颜色。
3. 手指拖动颜色球，调整发射方向。
4. 松开手指，颜色球加速向上飞行。
5. 颜色球击中灰色色块，为其增加一层颜色。
6. 色块集齐三次颜色命中后，完成复原。
7. 如果集齐红、黄、蓝三种不同颜色，则触发彩虹爆发。
8. 彩虹爆发可以影响周围的灰色色块，产生连锁反应。
9. 被复原的色块消失，同时增加世界复原进度。
10. 玩家持续操作，直到完成当前关卡的世界复原目标。

核心体验：

**选择颜色 → 拖拽瞄准 → 松手发射 → 击中上色 → 彩虹爆发 → 世界复苏。**

# 3. 游戏界面设计

采用竖屏布局。

## 3.1 屏幕区域

游戏界面分为三个主要区域。

### A. 顶部信息区

显示：

- 当前关卡。
- 世界复原进度。
- 剩余生命值。
- 暂停按钮。

世界复原进度采用一条彩色进度条。

游戏开始时进度条是灰色的，随着玩家完成色块，进度条逐渐出现颜色。

### B. 中间游戏区域

这是主要操作区域。

包含：

- 从顶部不断下落的灰色色块。
- 已经被染色的色块。
- 玩家发射的颜色球。
- 颜色命中效果。
- 彩虹爆发效果。

灰色色块可以采用圆角方块、柔软的几何形状，避免视觉上过于坚硬。

每个灰色色块内部有三个小型颜色区域，代表它需要被染色三次。

### C. 底部发射区

固定显示三个颜色球：

- 红色球。
- 黄色球。
- 蓝色球。

三个球始终位于屏幕底部。

它们是玩家的三个颜色发射器，而不是有限数量的弹药。

玩家可以随时选择其中一种颜色进行发射。

发射后，该颜色球短暂进入冷却状态，随后重新出现。

# 4. 核心交互：颜色球发射系统

这是整个游戏最重要的交互设计。

## 4.1 基础操作

玩家通过单指完成所有操作。

操作流程：

1. 按住底部的红色、黄色或蓝色球。
2. 将手指向上拖动。
3. 颜色球跟随手指移动，形成拖拽效果。
4. 屏幕显示一条半透明的预测轨迹。
5. 玩家调整方向，选择想要击中的灰色色块。
6. 松开手指。
7. 颜色球从底部发射位置脱离，沿预测轨迹向上加速飞行。
8. 命中目标后，产生颜色扩散效果。

拖拽的方向决定发射方向。

拖拽距离主要用于调整瞄准角度，不用于决定伤害。

建议限制发射方向，让球始终朝向屏幕上方，避免玩家向下发射。

## 4.2 颜色球的运动效果

颜色球不能像传统子弹一样直线高速射出。

它应该更像一个轻盈的气球，受到浮力影响，逐渐加速上升。

具体运动表现：

- 刚松手时，球体有一个轻微的弹出动作。
- 初始速度较慢。
- 飞行过程中逐渐加速。
- 球体左右轻微摆动。
- 球体表面有柔和的光晕。
- 飞行过程中留下短暂的彩色光迹。
- 接近目标时，速度可以略微增加。

建议第一版采用：

- 初始速度：约 250–350 px/s。
- 加速度：约 700–1000 px/s²。
- 最大速度：约 900–1100 px/s。

以上是原型初始参数，需要根据实际屏幕尺寸和操作手感调整。

注意：左右摆动主要用于视觉表现，实际碰撞轨迹应保持稳定，避免玩家瞄准时产生不确定性。

## 4.3 瞄准辅助

为了让休闲玩家更容易上手，建议加入轻量辅助。

拖动颜色球时：

- 显示一条半透明虚线。
- 虚线延伸到预计飞行路径。
- 如果路径上有灰色色块，该色块出现轻微高亮。
- 如果路径上有多个色块，优先命中最先接触的一个。

玩家不需要精确计算角度，只需要大致瞄准。

## 4.4 发射冷却

每个颜色球独立冷却。

建议：

- 发射后，该位置暂时出现一个空心圆环。
- 约 0.3–0.4 秒后，同色球重新出现。
- 不同颜色球可以连续发射。
- 不限制玩家选择颜色的次数。

这样既保留操作节奏，也不会让玩家因为弹药耗尽而感到挫败。

# 5. 色块系统

## 5.1 初始状态

所有从顶部出现的色块都是灰色的。

每个色块拥有三个待填充的颜色区域。

可以把它们设计成三个小花瓣。

初始状态：

- 三个花瓣全部灰色。
- 整个方块呈现灰白色。
- 没有明显生命力。

## 5.2 命中规则

颜色球击中灰色色块时：

1. 颜色球消失。
2. 产生一个颜色扩散动画。
3. 色块的一个空白区域被填充。
4. 色块记录本次命中的颜色。

每次命中只填充一个区域。

颜色命中没有顺序要求。

例如：

| 命中顺序 | 色块状态 | 结果 |
|---|---|---|
| 红 | 一个红色花瓣 | 1/3 |
| 红、黄 | 红黄双色 | 2/3 |
| 红、黄、蓝 | 三色齐全 | 彩虹复原 |
| 红、红、红 | 全红 | 普通复原 |
| 蓝、黄、蓝 | 蓝黄双色 | 普通复原 |

**核心规则：任何颜色都能增加一次进度，重复颜色也有效。**

玩家不需要记忆复杂的颜色混合公式。

## 5.3 三种复原状态

| 状态 | 表现 |
|---|---|
| 0/3 | 完全灰色 |
| 1/3 | 一个花瓣出现颜色 |
| 2/3 | 两个花瓣出现颜色 |
| 3/3 | 完全复原，触发消除动画 |

完成三次命中后，色块消失。

如果三个花瓣分别是红、黄、蓝，则触发更高级的彩虹效果。

# 6. 彩虹爆发系统

这是游戏的核心策略机制。

## 6.1 彩虹触发条件

一个色块必须同时获得：

- 红色命中。
- 黄色命中。
- 蓝色命中。

三种颜色全部集齐后，色块完成彩虹复原。

不要求固定顺序。

## 6.2 彩虹爆发效果

触发时：

1. 色块瞬间变成流动的彩虹色。
2. 方块轻微膨胀。
3. 中心出现一道明亮光芒。
4. 方块绽放并消失。
5. 释放彩虹冲击波。
6. 冲击波影响周围灰色色块。

普通复原和彩虹复原的视觉效果必须有明显区别。

普通复原：柔和的颜色绽放。

彩虹复原：更强烈的光效、粒子、音效和范围传播。

## 6.3 连锁反应

彩虹爆发可以影响周围的灰色色块。

建议第一版采用以下规则：

- 以爆发点为中心，设定一个固定影响半径。
- 半径内的灰色色块各获得一次额外命中。
- 这次额外命中的颜色采用触发爆发的最后一种颜色。
- 如果附近色块因此达到三次命中，则直接复原。
- 如果附近色块也满足红黄蓝三色条件，可以继续触发彩虹爆发。

例如：

一个色块通过红、黄、蓝三次命中完成复原。

它产生彩虹爆发。

周围三个灰色色块分别增加一次蓝色命中。

其中一个色块原本已经有红色和黄色，因此直接完成彩虹复原。

它再次产生爆发。

最终形成连续的彩虹连锁。

连锁次数越多，玩家获得的额外分数越高。

注意：连锁影响范围要有限制，避免屏幕上所有色块同时消失，失去策略感。

---

# 7. 色块下落系统

## 7.1 下落方式

灰色色块从屏幕顶部生成，逐渐向下移动。

初始建议采用 6 列的布局。

色块可以在不同列出现，也可以有不同的水平排列方式。

不要一开始就加入复杂物理碰撞。

第一版采用简单、稳定的下落运动即可。

## 7.2 下落速度

随着关卡推进：

- 色块生成频率逐渐增加。
- 下落速度逐渐增加。
- 同时出现的色块数量增加。
- 色块之间的间距逐渐缩小。

难度主要通过数量、速度和位置变化来控制。

不要过早增加复杂颜色规则。

## 7.3 失败条件

屏幕底部设置一条危险线。

如果灰色色块越过危险线：

- 玩家失去一颗生命值。
- 该色块从屏幕移除。
- 播放轻微的灰雾扩散动画。

初始设置三颗生命值。

当生命值全部消耗后，游戏结束。

# 8. 世界复原系统

这是游戏区别于普通射击消除游戏的核心特色。

玩家不是为了消除方块而消除方块，而是在逐渐恢复一个失去色彩的世界。

## 8.1 世界复原进度

每完成一个灰色色块，就增加世界复原进度。

建议设置四个明显阶段：

### 0%：灰色世界

- 天空灰白。
- 草地灰暗。
- 花朵没有颜色。
- 环境安静。
- 背景有轻微灰雾。

### 25%：光线恢复

- 灰雾逐渐散去。
- 天空开始出现淡淡的蓝色。
- 阳光出现。
- 背景亮度增加。

### 50%：自然恢复

- 草地变绿。
- 花朵逐渐出现颜色。
- 树木开始恢复。
- 出现轻微的风声。

### 75%：生命恢复

- 蝴蝶出现。
- 小鸟飞过。
- 花朵开始摇摆。
- 背景音乐变得丰富。

### 100%：世界复苏

- 整个场景恢复色彩。
- 出现完整的环境动画。
- 播放一段温暖的完成音乐。
- 展示当前世界的完整彩色画面。

## 8.2 视觉反馈原则

不要等到关卡结束才改变背景。

每完成几个色块，都应该让玩家看到世界正在发生变化。

玩家应该能够明显感受到自己的操作正在产生价值。

# 9. 关卡设计

## 第一阶段：基础教学（1–5关）

目标：理解颜色球发射和色块复原。

| 关卡 | 设计内容 |
|---|---|
| 1 | 只有少量灰色色块，学习拖拽和发射 |
| 2 | 学习选择不同颜色 |
| 3 | 学习三次命中复原 |
| 4 | 学习红黄蓝三色组合 |
| 5 | 第一次体验彩虹爆发和连锁 |

第一阶段不加入特殊方块。

## 第二阶段：轻度策略（6–15关）

- 色块数量增加。
- 出现多列色块。
- 不同位置的色块有不同下落速度。
- 玩家需要选择优先攻击的目标。
- 开始利用彩虹爆发处理密集区域。

## 第三阶段：特殊机制（16关以后）

可以逐步加入：

| 特殊色块 | 效果 |
|---|---|
| 坚硬色块 | 需要四次命中 |
| 脆弱色块 | 只需要一次命中 |
| 灰雾色块 | 暂时遮挡附近色块 |
| 光之色块 | 完成后产生更大的爆发范围 |

这些机制属于后续扩展，不属于第一版必需内容。

# 10. 世界主题

游戏通过不同主题区域，让玩家获得长期探索动力。

建议第一版规划四个世界。

| 世界 | 初始状态 | 复原后 |
|---|---|---|
| 灰色花园 | 枯萎花朵、灰色草地 | 鲜花盛开、蝴蝶飞舞 |
| 沉寂城市 | 灰色建筑、没有灯光 | 霓虹灯亮起、街道恢复 |
| 失色海洋 | 灰色海水、没有生命 | 蓝色海洋、鱼群出现 |
| 沉睡森林 | 枯萎树木、灰暗环境 | 绿色森林、动物出现 |

每个世界都可以拥有自己的：

- 背景音乐。
- 颜色主题。
- 环境动画。
- 特殊视觉效果。
- 关卡布局。

# 11. 美术风格

## 11.1 整体风格

建议采用：

**梦幻治愈风 + 简洁几何游戏元素。**

游戏世界采用柔和、温暖、具有生命力的视觉风格。

游戏操作元素则保持清晰、简洁。

## 11.2 灰色世界

- 灰白色。
- 低饱和度。
- 柔和阴影。
- 轻微雾化。
- 缺乏明显动态。

## 11.3 彩色世界

- 柔和的红、黄、蓝。
- 高质量渐变。
- 颜色扩散效果。
- 透明粒子。
- 柔和光晕。
- 彩虹流动效果。

## 11.4 颜色球设计

三个球应该有明显区别：

- 红色球：温暖、活跃。
- 黄色球：明亮、轻快。
- 蓝色球：平静、柔和。

球体表面可以有轻微的果冻质感。

球体运动时可以产生轻微变形，松手时有弹性拉伸效果。

## 11.5 色块设计

初始为灰色的圆角几何块。

内部有三个小型花瓣形状的颜色区域。

被命中时，颜色从中心向外扩散，像颜料滴入水中。

完全复原时，色块可以变成一朵小花或一个彩色生命体。

# 12. 声音设计

声音应该随着世界恢复逐渐变得丰富。

| 游戏事件 | 声音 |
|---|---|
| 拖动颜色球 | 柔和的气泡声 |
| 松手发射 | 轻盈的弹射声 |
| 颜色球上升 | 轻微的空气流动声 |
| 命中色块 | 清脆的水滴声 |
| 第一次上色 | 柔和的音符 |
| 普通复原 | 花朵绽放声 |
| 彩虹爆发 | 丰富的和弦 |
| 连锁反应 | 音调逐渐上升 |
| 世界复原 | 完整的温暖旋律 |

特别建议：

游戏开始时背景音乐只有简单的钢琴音。

随着世界复原，逐渐加入更多乐器和环境声音。

最终让玩家感受到一个世界从沉寂到鲜活的过程。

# 13. 分数和奖励系统

建议采用简单的积分规则。

| 行为 | 奖励 |
|---|---|
| 普通命中 | 基础分 |
| 完成普通复原 | 额外分数 |
| 完成三色复原 | 彩虹奖励 |
| 触发连锁 | 连锁奖励 |
| 连续多次命中 | 连击奖励 |
| 完成世界 | 关卡星级奖励 |

彩虹连锁应该是最高价值的得分来源。

但普通复原也必须有足够的正反馈。

不能让玩家觉得只有刻意凑齐三色才有意义。

# 14. MVP 第一版开发范围

第一版不要实现所有系统。

优先验证核心操作是否有趣。

## 必须实现

| 模块 | 内容 |
|---|---|
| 游戏场景 | 一个灰色花园 |
| 屏幕布局 | 竖屏 |
| 颜色球 | 红、黄、蓝三个固定发射器 |
| 拖拽操作 | 拖动球体调整方向 |
| 发射动作 | 松手后加速向上飞行 |
| 碰撞系统 | 颜色球命中灰色色块 |
| 色块状态 | 三次命中完成复原 |
| 颜色记录 | 记录每次命中的颜色 |
| 彩虹系统 | 三色齐全触发爆发 |
| 连锁系统 | 爆发给周围色块增加一次命中 |
| 下落系统 | 灰色色块持续下落 |
| 生命系统 | 三次漏过后失败 |
| 世界复原 | 背景根据进度逐渐恢复色彩 |

## 暂时不实现

- 多个世界地图。
- 复杂特殊色块。
- 角色养成。
- 道具系统。
- 每日任务。
- 商店。
- 社交系统。
- 复杂的剧情动画。

先把最核心的游戏体验做好。

# 15. 第一版需要重点验证的指标

开发完成后，重点测试：

### 操作体验

- 玩家是否能快速理解拖拽发射？
- 瞄准是否足够准确？
- 颜色球的加速上升是否有吸引力？
- 连续发射是否流畅？

### 核心玩法

# 16. 核心设计原则

整个游戏开发过程中，需要始终坚持以下原则：

**1. 操作简单**

底部只有三个颜色球，拖动、瞄准、松手即可完成操作。

**2. 颜色规则简单**

任何颜色都可以增加一次上色进度，不需要复杂的颜色混合计算。

**3. 命中反馈明显**

每一次射击都必须有明确的视觉和声音反馈。

**4. 连锁反应有爽感**

三色齐全应该成为玩家主动追求的高级玩法。

**5. 世界恢复是最终奖励**

游戏的核心不是消除，而是让世界重新拥有色彩。

# 17. 当前版本的核心玩法定义

《拾色者》是一款通过拖拽发射颜色球，让灰色世界逐渐恢复色彩的休闲游戏。

玩家在屏幕底部拥有三个颜色球：红、黄、蓝。

玩家选择其中一个球，向上拖拽，调整发射方向，然后松开手指。

颜色球像一个轻盈的气球一样加速上升，击中从顶部不断下落的灰色色块。

每个灰色色块需要三次命中才能完成复原。

如果三次命中分别是红、黄、蓝，就会触发彩虹爆发，影响周围的其他灰色色块。

随着玩家不断完成复原，游戏背景从灰暗逐渐变得五彩缤纷。

**最终目标：让玩家通过每一次简单的拖拽和发射，亲手恢复一个失去色彩的世界。**
